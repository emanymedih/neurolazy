# Комбинации

Комбинации собираются только после того, как для каждой черты зафиксирована собственная функция.

## Порядок сборки

1. Определить функциональный блок.
2. Выбрать 2–3 черты.
3. Назначить каждой отдельную роль в причинной цепочке.
4. Проверить, что роли не дублируются.
5. Сформулировать общий сценарий.
6. Проверить противоположный полюс каждой черты.
7. Отделить прямые положения источника от синтеза.

## Формат карточки

- исходные черты;
- функция каждой;
- тип взаимодействия;
- общий механизм;
- сильные стороны;
- уязвимости;
- условия усиления;
- компенсаторы;
- пример задачи;
- следующий параметр для уточнения.
