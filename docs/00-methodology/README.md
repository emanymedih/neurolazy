# Метод анализа

## Единица анализа

Каждая черта сначала описывается отдельно. Для неё фиксируются:

- основная функция;
- полюса параметра;
- сильные стороны;
- уязвимости;
- условия усиления и ослабления;
- антагонисты, усилители и компенсаторы;
- границы применимости.

## Проверка вывода

Перед включением утверждения в итоговое описание нужно ответить на четыре вопроса:

1. Какая исходная черта даёт этот эффект?
2. Входит ли вывод в её функциональную компетенцию?
3. Является ли это прямым положением источника или логическим синтезом?
4. Какая другая черта способна изменить проявление?

Если происхождение вывода проследить нельзя, он исключается.

## Синтез

В одной микросвязке объединяются 2–3 черты. Рабочая последовательность:

- импульс — что запускает процесс;
- алгоритм — как обрабатывается ситуация;
- фильтр/награда — что считается значимым результатом;
- поведение — как связка проявится в задаче.

## Функциональные блоки

- действия: челюсть + подбородок;
- восприятие: губы и рот + глаза + уши;
- анализ информации: нос + лоб;
- общение: лоб + брови + челюсть + подбородок + глаза + губы.

Случайные связи между любыми чертами не создаются без функционального основания.

## Контроль качества

Отдельно проверяются:

- дублирование одного свойства двумя родственными признаками;
- слишком широкий вывод из локальной функции;
- подмена механизма красивой формулировкой;
- смешение одинаковых слов с разной функцией;
- чрезмерная конкретизация примера;
- медицинские и нейробиологические утверждения без внешней проверки.
