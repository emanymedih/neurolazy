# Шаблон карточки параметра

## Основная функция

Одно предложение: за что именно отвечает параметр.

## Полюса

Для каждого полюса:
- определение;
- механизм в рамках материала;
- 3–5 сильных сторон;
- 3–5 уязвимостей;
- наблюдаемые проявления;
- условия усиления;
- условия ослабления.

## Границы функции

Что этому параметру нельзя приписывать без дополнительных черт.

## Взаимодействия

- антагонист;
- усилители;
- компенсаторы;
- модуляторы;
- ортогональные признаки.

- прямое положение источника;
- логический синтез;
- гипотеза;
- внешний научный факт.
