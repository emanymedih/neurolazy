# neurolazy

Структурированная база материалов проекта «Нейро».

## Цель

Собрать исходные параметры, функциональные зоны, отдельные черты и правила их комбинирования в систему, где каждый вывод можно проследить до исходной функции признака.

## Принцип работы

1. Сначала фиксируется функция отдельной черты.
2. Затем определяется её зона компетенции.
3. Комбинации строятся внутри функциональных блоков.
4. Итоговая связка раскладывается на импульс, алгоритм, фильтр/награду и наблюдаемое поведение.
5. Прямые положения источника отделяются от логического синтеза и гипотез.
6. Составная черта и её часть не считаются двумя независимыми подтверждениями.
7. Сходные слова проверяются по функции: одинаковый термин может описывать разные механизмы.

## Эпистемический статус

Репозиторий систематизирует положения предоставленных учебных материалов. Связи между морфологией лица и психологическими свойствами рассматриваются здесь как положения этой модели. Биологические и нейрофизиологические объяснения считаются установленными фактами только после отдельной внешней проверки; без неё они маркируются как объяснение источника.
