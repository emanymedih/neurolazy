# Карта исходных материалов

Репозиторий собирается по материалам проекта «Нейро». Содержание переносится в структурированные карточки, а исходные бинарные файлы пока остаются в рабочем проекте.

## Приоритет редакций

При конфликте версий фиксируется сам конфликт. Более поздняя редакция используется как рабочая после явной маркировки изменения.

## Статус утверждений

Каждая карточка должна различать прямое положение источника, логический синтез, рабочую гипотезу и отдельно проверенный научный факт.
